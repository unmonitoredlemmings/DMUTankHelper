# DMU Tank Helper

An accessibility-focused Dalamud overlay for all eight raid roles using the MUR/OCE Bowels of Agony strategy in Dancing Mad (Ultimate) Phase 3.

## Install

1. In FFXIV, run `/xlsettings`.
2. Open **Experimental** and find **Custom Plugin Repositories**.
3. Add:

   `https://raw.githubusercontent.com/unmonitoredlemmings/DMUTankHelper/main/pluginmaster.json`

4. Save, then run `/xlplugins`.
5. Search for **DMU Tank Helper** and install it.
6. Run `/dmuhelper`, select MT, OT, H1, H2, or D1-D4, preview and position the overlay, then lock it.

## Commands

- `/dmuhelper` — open settings
- `/dmuhelper test` — preview the overlay
- `/dmuclear` — clear callouts and reset the timeline

## Features

- MT/OT/H1/H2/D1-D4 assignment and role-filtered warnings
- Optional Tank LB3 responsibility for MT or OT
- Entropy, Dynamic Fluid, Headwind and Tailwind instructions
- Thunder III hit 1/hit 2 instructions
- Implosion and Vacuum Wave callouts
- Movable, lockable, high-contrast overlay
- Automatic wipe/combat reset and manual clear

## Disclaimer

This is an unofficial third-party tool and is not approved by Square Enix. It does not move characters, press actions, place markers, or send game inputs. Validate live encounter recognition during safe practice before relying on it.
